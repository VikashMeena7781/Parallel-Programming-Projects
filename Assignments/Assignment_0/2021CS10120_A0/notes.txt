g++ -O3 -g -o main main.cpp

----------To Activate perf------------ 
sudo apt-get update && apt-get -y install linux-tools-generic
sudo ln -s "$(find /usr/lib/linux-tools/*/perf | head -1)" /usr/local/bin/perf

----------For using perf------------- 
perf stat -e task-clock,cycles,instructions,cache-references,cache-misses -d ./main 0 1000 1000 1000 ./input_path/ ./output_path/ > output.txt 2>&1

task-clock: Measures the total time (in milliseconds) spent executing tasks.
cycles: Counts the number of CPU cycles.
instructions: Counts the number of instructions executed.
cache-references: Measures the total cache accesses.
cache-misses: Measures the total cache misses.
-------------------------------------------------------------------------------
perf record -g -F 1000 ./main 0 1000 1000 1000 ./input_path/ ./output_path/
perf report > perf_report.txt

To get the CPU time spent in individual functions (matrixMultiplyXYZ, readMatrix, writeMatrix), 
you need to use perf record and analyze the output using perf report.
-----------------------------------------------------------------------------------------------------------------


-----------------For gprof------------------------
g++ -pg -o main main.cpp
If you're using make, modify the CFLAGS in the Makefile to include -pg:
CFLAGS = -pg -O2
./main 0 1000 1000 1000 ./input_path/ ./output_path/
gprof ./main gmon.out > gprof_report.txt
---------- For graph ---------------
gprof main gmon.out | gprof2dot | dot -Tpng -o callgraph.png
